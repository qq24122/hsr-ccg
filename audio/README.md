# 音乐与语音

这个目录放 **BGM** 和 **随从语音**。两者都是可选的：文件不在，游戏就静默跳过，
不报错、不卡顿。**音效（抽卡 / 出牌 / 攻击 / 最后一击 等）不在这里**——那些是
`src/audio.js` 现场合成的，一直都在，不需要任何文件。

## 怎么加

1. 把音频文件直接丢进这个目录（`mp3` / `ogg` / `m4a` 都行）
2. 编辑 `manifest.json`：

```json
{
  "bgm": ["bgm-battle.mp3", "bgm-menu.mp3"],
  "voice": {
    "H001": "voice-H001.mp3",
    "N022": "voice-N022.mp3"
  }
}
```

- **`bgm`** 是列表，每局开始时随机挑一首循环播放。
- **`voice`** 的键是**卡牌 id**（卡表 `data/cards-*.tsv` 的第一列，例如 `H001`、`N022`），
  召唤那张随从时播放对应文件。只给你在意的那几张配就行，没配的静默。

改完刷新页面即生效，代码不用动。

## 为什么要 manifest，不能直接扫目录

浏览器读不了目录列表。如果不给清单，就得对每张卡都试着请求一次
`voice-<id>.mp3`——一局下来几十个 404，既慢又把访问日志刷满。
有了清单，只请求真实存在的文件。

`manifest.json` 被删掉或写坏时，BGM 与语音整体关闭（只发出一次请求），音效照常。

## 几件实际要注意的事

**录宣传视频时把 BGM 关掉。** 游戏里响过的音乐会一起录进视频，
B站 会对视频音轨做版权识别，命中可能导致静音、贴片广告或限流，而且作者
往往不会收到明确预警。开局界面的「声音」选项里有「只要音效」这一档，就是为此准备的。
音乐想要就在剪辑软件里单独加，那样你能控制它出现在哪一段。

**文件大小。** 一首 3 分钟 128kbps 的 mp3 约 2.9MB。GitHub Pages 免费额度是
100GB/月，按 3MB 一次算够约 3 万次播放；仓库上限 1GB。放两三首没问题，
放整张原声集就要留意了。

**格式。** Safari 对 `ogg` 支持不完整，`mp3` 兼容性最好。语音这类一两秒的短音
建议 `mp3`，会被解码进内存以便和音效精确同时发声；BGM 是边下边播，不占内存。
